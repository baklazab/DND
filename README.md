# D&D 2024: Tvorba postavy

Tato aplikace slouží výhradně k tvorbě a přehledu hráčské postavy. Zobrazuje jméno, rasu, třídu, úroveň, atributy, záchranné hody, inventář a vybavení.

## Rozsah aplikace

- tvorba postavy a výběr rasy, třídy a pozadí
- zobrazení základních statistik a modifikátorů
- výpočet HP, AC, iniciativy a pasivního vnímání
- správu vybavení a inventáře
- uložení a návrat k vytvořené postavě

## Oficiální zdroje

- SRD_CC_v5.2.1.pdf (D&D 2024 System Reference Document, CC-BY 4.0)
- pravidla/zdroje/tvorba-postavy-2024.txt
- svet/zdroje/specifikace-sveta-a-kampane.txt
- handouty/zdroje/pamflet-h.html

## Omezení

Aplikace pracuje pouze s oficiálními daty a neobsahuje žádnou fiktivní kampanickou linii, svět, lore ani příběhovou mapu. Jakýkoli nový obsah musí být explicitně přidán jako nový oficiální zdroj, ne jako domácí story text v aplikaci.
